# B1

Writing at B1: what B1 is here, the page's language, its tags, and what it is measured against.
**`src/data/navigation.ts` is the truth about what exists.** The other rungs: [`a1.md`](a1.md),
[`a2.md`](a2.md), [`b2.md`](b2.md).

**B1 is offered while being written** (#74) and **lists everything A2 does** (#76): it is A2 plus
whatever is written at B1's own floor.

## What B1 material is

Two kinds, and nothing else:

- **A new point whose floor is B1** — a page tagged `from("B1")`, placed after the A2 pages of its
  chapter because it is built on them. The first ones are in `grammaire`; count them in the
  manifest.
- **A harder set on a page with no floor** — the B1 questions of a `lecture` text, the B1 bank of a
  drill (`perLevel`, #68, #76). How: `lesson-author.md` (« The harder set asks more of the same
  page »). **Read the A2 set before writing the B1 one, every time.**

**Never a B1 copy of an A2 page** (#76): the A2 page is already listed here.

**Not every text can carry a B1 set honestly** — past a point a harder question is trivia. Tag a
`perLevel` page for the levels it can actually serve.

## The page is French only (#53)

Everything in [`a2.md`](a2.md) holds. **The explanation may use what A2 taught, never the point
on the page**: a page on *ce dont* may not explain itself with *dont*.

## How a page is tagged

- **`from("B1")`** — listed at B1 and B2.
- **A `perLevel` page lists exactly the levels it has material for** — `A2B1` today. Adding a B1
  set to a page that has none is a key change (AGENTS.md §8).
- **A DELF épreuve is `["B1"]`**, never `from()`.
- **A `delf` descriptor is per level** on a `perLevel` page — `{ A2: '…', B1: '…' }` — because it
  says what that level's questions check.

## What it is measured against

**DELF B1** (#15), from the same *Inventaire* Annexe E. **B1 has no syllabus map** (AGENTS.md
§12.2). **Before a batch of B1 work, write it here** — FONCTIONS as the gate, the GRAMMAIRE points,
and the page covering each — so the order comes from the syllabus.
