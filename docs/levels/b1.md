# B1

The context for writing at B1: what B1 is in this course, the page's language, how it is tagged,
and what it is measured against. **`src/data/navigation.ts` is the truth about what exists** —
count there, not here. The other rungs: [`a1.md`](a1.md), [`a2.md`](a2.md), [`b2.md`](b2.md).

**B1 is offered while it is being written** (#74), and **it already lists everything A2 does**
(#76). So B1 is never "empty" — it is A2 plus whatever has been written at B1's own floor.

## What B1 material is

Two kinds, and nothing else:

- **A new point whose floor is B1** — a page tagged `from("B1")`, placed after the A2 pages of its
  chapter because it is built on them. The first ones are in `grammaire`; count them in the
  manifest.
- **A harder set on a page with no floor** — the B1 questions of a `lecture` text, the B1 bank of a
  drill (`perLevel`, #68, #76). How to write one is in `lesson-author.md` (« The harder set asks more
  of the same page »). **Read the A2 set before writing the B1 one, every time.**

**Never a B1 copy of an A2 page** (#76). There is nothing new to say about the imparfait at B1; the
A2 page is already listed here. A "B1 twin" of an A2 page is the duplication #14 and #23 reject.

**Not every text can carry a B1 set honestly.** Past a point a harder question is trivia or literary
analysis the page never prepared. Tag a `perLevel` page for the levels it can actually serve.

## The page is French only (#53)

Everything in [`a2.md`](a2.md) holds. **The explanation stays easier than the French it teaches**:
a page on *ce dont* may not explain itself with *dont*. The reader has A2 behind them, so the
explanation may use what A2 taught — the imparfait, the pronouns — but not the point on the page.

## How a page is tagged

- **`from("B1")`** — listed at B1 and B2.
- **A `perLevel` page lists exactly the levels it has material for** — `A2B1` today. Adding a B1
  set to a page that has none is a key change: read AGENTS.md §8 on `perLevel` before touching it.
- **A DELF épreuve is `["B1"]`**, never `from()`.
- **A `delf` descriptor is per level** on a `perLevel` page — `{ A2: '…', B1: '…' }` — because it
  says what that level's questions check.

## What it is measured against

**DELF B1** (#15), from the same *Inventaire* Annexe E as A1 and A2. **B1 has no syllabus map**
(AGENTS.md §12.2): its pages are being chosen one at a time. **Before a batch of B1 work, write the
map here** — the FONCTIONS as the gate, the GRAMMAIRE points, and against each the page that covers
it — so the order comes from the syllabus rather than from whichever page is most fun to write.
