# le-petit-cours Agent

This agent is tuned for the `le-petit-cours` Vue 3 + Vite app:

- Vue Router route/file structure and dynamic page imports
- PWA assets and offline behavior via `vite-plugin-pwa` and service worker files
- French learning content in `src/views` and the app layout components
- Minimal, project-specific code changes

## Focus areas

- Maintain the existing app structure and style
- Add or update pages, routes, and navigation
- Fix component issues and content rendering
- Support app build and PWA behavior in the local workspace

## Recommended usage

Ask this agent for tasks like:

- "Create a new module in `src/views/orthographe`"
- "Help me update `src/views/prononciation/index.vue`"
- "Adjust the router to include a new lesson path"
- "Audit the PWA files and suggest improvements"

If you want, I can also add a second agent for content editing only, or a more specialized PWA deployment assistant next.
